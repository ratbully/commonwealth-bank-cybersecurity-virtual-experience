## Tasks Completed

### Task 1 – Data Analysis and Fraud Detection

**Tool:** Splunk Enterprise

For this task, I worked with a prepared transaction dataset and used Splunk Enterprise to explore and analyse fraudulent transaction patterns.

Activities completed:
- Installed and configured Splunk Enterprise.
- Imported the prepared CSV dataset.
- Explored the dataset using the Interesting Fields section.
- Used Splunk Search Processing Language (SPL).
- Analysed fraudulent transactions by age, gender, category, merchant and transaction step.
- Built a Fraud Detection Dashboard.
- Troubleshot search execution and disk-space issues.

**Project evidence:**
- Dashboard screenshots: `task-01-data-analysis/dashboard-screenshots/`
- Dashboard PDF: `task-01-data-analysis/dashboard-export.pdf`
