# Task 1 – Data Analysis and Fraud Detection

## Project Overview

This task involved using Splunk Enterprise to analyse a prepared transaction dataset and build a Fraud Detection Dashboard.

## Activities Completed

- Installed Splunk Enterprise.
- Imported the prepared CSV dataset.
- Explored the dataset using Interesting Fields.
- Analysed transaction records using SPL.
- Created dashboard panels to examine fraudulent transactions.
- Investigated and resolved a disk-space issue affecting searches.
- Completed the Fraud Detection Dashboard.

## Dashboard Analysis

The dashboard contains visualisations covering:

- Fraudulent transactions.
- Fraudulent transactions by age.
- Fraudulent transactions by gender.
- Top 10 merchants by fraudulent transactions.
- Fraudulent transactions by step.
- Fraud by gender and category.
- Top 10 fraudulent age-merchant combinations.
- Transaction counts by category.

## Tools Used

- Splunk Enterprise
- Splunk Search Processing Language (SPL)
- CSV dataset
