# Project Findings — Fraud Detection Analysis

## 1. Introduction

This document presents the findings from my fraud detection analysis using Splunk Enterprise as part of the Commonwealth Bank Cybersecurity Virtual Experience.

The analysis focused on identifying patterns in fraudulent transactions based on age, gender, merchant, category and transaction step.

## 2. Analysis Performed

The following areas were investigated:

- Total transactions by category.
- Number of fraudulent transactions.
- Fraudulent transactions by age group.
- Fraudulent transactions by gender.
- Top 10 merchants associated with fraudulent transactions.
- Fraudulent transactions by transaction step.
- Fraud patterns by gender and category.
- Fraud patterns by age and merchant.

## 3. Key Findings

Completed these sections using the actual results displayed in your Splunk dashboard.
