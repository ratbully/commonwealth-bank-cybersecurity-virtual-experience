**Incident Response Recommendations
Commonwealth Bank Cybersecurity Virtual Experience**

**Task: 02 – Cyber Security Incident Response**

**1. Introduction**

This document outlines recommendations for improving the organisation's cyber security posture following a phishing and suspected ransomware incident.

The incident involved fraudulent HR emails, credential theft, malicious software distribution, and reports of inaccessible shared files.

The recommendations focus on reducing the likelihood of similar attacks, improving incident detection, protecting sensitive information, and strengthening the organisation's incident response capabilities.

**2. Immediate Security Recommendations**

The following actions should be prioritised to protect the organisation:

**1. Strengthen Email Security**

Implement advanced email filtering to detect phishing messages.
Block suspicious attachments and malicious URLs.
Configure email authentication protocols such as SPF, DKIM, and DMARC.
Monitor suspicious email activity and remove confirmed phishing messages from employee inboxes.

**2. Improve Account Security**

Enforce multi-factor authentication (MFA) across company systems.
Reset credentials for employees whose accounts may have been compromised.
Revoke active sessions and authentication tokens where necessary.
Monitor unusual login attempts and suspicious account activity.
Apply the principle of least privilege to user accounts.

**3. Strengthen Endpoint Protection**

Deploy endpoint detection and response (EDR) solutions.
Keep antivirus and endpoint security software updated.
Regularly patch operating systems and applications.
Monitor devices for suspicious processes and malicious software.
Isolate potentially compromised devices during investigations.

**4. Ransomware Prevention and Data Protection**

To reduce the risk of future ransomware incidents, I recommend:

Maintain regular and secure backups of critical business information.
Store offline or otherwise isolated backup copies.
Encrypt sensitive data and protect backup access.
Regularly test backup restoration procedures.
Implement network segmentation to limit malware spread.
Restrict unnecessary access to shared drives and sensitive folders.
Monitor unusual file modifications and mass encryption behaviour.
Establish documented procedures for restoring affected systems.

**5. Employee Security Awareness**

Employees are an important part of an organisation's cyber security defence.

The following measures should be implemented:

Conduct regular cyber security awareness training.
Organise phishing simulation exercises to help employees recognise fraudulent emails.
Teach employees to inspect suspicious links before opening them.
Encourage employees to verify unusual HR or management requests through trusted communication channels.
Explain the risks of entering credentials into unfamiliar websites.
Establish a simple process for reporting suspicious emails to the IT Service Desk.
Provide refresher training on social engineering and ransomware threats.

**6. Incident Detection and Monitoring**

The organisation should improve its ability to detect cyber threats before they cause significant damage.

Recommended measures include:

Implement Security Information and Event Management (SIEM) monitoring.
Collect and analyse logs from endpoints, servers, firewalls, and authentication systems.
Monitor unusual login locations and repeated failed authentication attempts.
Detect suspicious network connections and malicious downloads.
Monitor shared file systems for unusual access or modification patterns.
Establish security alerts for potential ransomware activity.
Conduct regular vulnerability assessments and security reviews.

**7. Incident Response Improvements**

An effective incident response plan helps an organisation respond quickly and consistently to cyber attacks.

I recommend the following improvements:

**Preparation**

Establish a clearly defined incident response team.
Assign responsibilities to IT, security, management, and relevant business departments.
Maintain updated incident response procedures.
Conduct regular incident response exercises.

**Identification**

Establish clear processes for reporting suspicious activity.
Investigate security alerts and employee reports promptly.
Identify affected users, systems, and data.
Preserve evidence for forensic investigation.

**Containment**

Isolate infected devices.
Disable compromised accounts where necessary.
Block confirmed malicious websites and network indicators.
Prevent further unauthorised access.

**Eradication**

Remove malicious software.
Identify and address the original point of compromise.
Patch vulnerabilities and secure affected accounts.
Verify that attackers no longer have access.

**Recovery**

Restore systems and files from verified clean backups.
Test affected systems before reconnecting them.
Monitor recovered systems for further suspicious activity.
Confirm that normal business operations have resumed.

**Lessons Learned**

Review the effectiveness of the response.
Document weaknesses and areas for improvement.
Update security policies and procedures.
Share relevant lessons with employees and stakeholders.


### 8. Recommended Security Controls

| Security Control | Purpose |
| :--- | :--- |
| Multi-factor authentication (MFA) | Reduces the risk of unauthorised account access. |
| Email security filtering | Detects and blocks phishing emails. |
| Endpoint detection and response (EDR) | Helps identify and investigate malicious activity. |
| Regular backups | Supports recovery from ransomware incidents. |
| Network segmentation | Limits the spread of malware. |
| Security awareness training | Helps employees recognise cyber threats. |
| SIEM monitoring | Supports centralised security monitoring and detection. |
| Regular patching | Reduces exposure to known vulnerabilities. |
| Access control | Restricts access to sensitive systems and information. |
| Incident response exercises | Improves preparedness and response effectiveness. |


**9. Conclusion**

The phishing and suspected ransomware incident demonstrates the importance of having strong preventive and reactive cyber security controls.
Although technical security solutions are essential, employees must also understand how to recognise and report suspicious activity.
By strengthening email security, enforcing multi-factor authentication, maintaining secure backups, improving monitoring, and regularly testing incident response procedures, the organisation can reduce the likelihood and impact of similar incidents.
These recommendations will help strengthen the organisation's resilience, protect sensitive information, and support the continuity of business operations.
