**3. Understanding Password Security**

Passwords are used to protect access to personal accounts, business applications, networks, and sensitive information.

Weak or reused passwords create security risks because cybercriminals may use stolen credentials to gain unauthorised access to multiple accounts.

Common password-related threats include:

Brute-force attacks: Attackers attempt to guess passwords by trying many possible combinations.

Credential stuffing: Attackers use previously stolen usernames and passwords to attempt access to other accounts.

Phishing: Cybercriminals trick employees into revealing their login credentials through fraudulent emails and websites.

Password spraying: Attackers try commonly used passwords against multiple accounts.

These threats demonstrate why strong and unique passwords are essential for protecting organisational information.

**4. ACSC Recommendations for Secure Passwords**

Based on Australian Cyber Security Centre guidance, the following practices help improve password security:

**1. Create long passwords**

Use passwords of at least 15 characters where traditional passwords are required. Longer passwords are generally harder to guess.

**2. Make passwords unpredictable**

Avoid personal information, common words, predictable patterns, and easily guessed combinations.

**3. Use unique passwords**

Never reuse the same password across multiple accounts. Each account should have its own password.

**4. Use a password manager**

A trusted password manager can generate, store, and manage strong passwords securely.

**5. Enable multi-factor authentication**

Use MFA to add another layer of protection when accessing important accounts.

**6. Consider passkeys**

Where supported, use passkeys as a more secure alternative to traditional password-based login.

**7. Password Management Best Practices**

Employees should follow these practices to protect their accounts:

Never share passwords with colleagues or other individuals.
Avoid writing passwords in easily accessible places.
Do not use personal information in passwords.
Avoid reusing passwords between personal and work accounts.
Use trusted password management software.
Change passwords immediately if they are suspected to be compromised.
Be cautious of suspicious emails requesting login information.
Never enter credentials into unfamiliar or unverified websites.
Enable MFA on important accounts.
Report suspicious login activity to the IT security team.
