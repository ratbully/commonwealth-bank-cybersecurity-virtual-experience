**Password Security Guidelines**
**Commonwealth Bank Cybersecurity Virtual Experience**

**Task: 03 – Security Awareness**

**1. Introduction**

Password security is an essential part of protecting personal information, business systems, and sensitive organisational data.

Weak or reused passwords can allow cybercriminals to gain unauthorised access to accounts, networks, and confidential information.

The Australian Cyber Security Centre (ACSC) provides guidance to help individuals and organisations create, manage, and protect secure passwords.

This document examines the ACSC recommendations and explains how employees can apply effective password security practices to protect themselves and their organisation.

**2. Objectives**

The main objectives of this research are to:

Understand the importance of password security.
Identify common password-related cyber attacks.
Research ACSC recommendations for creating strong passwords.
Understand the importance of unique passwords and passphrases.
Learn how password managers improve password security.
Understand the benefits of multi-factor authentication.
Promote safer password management practices among employees.

**3. Understanding Password Security**

Passwords protect access to personal accounts, business applications, computer networks, and sensitive information.

When passwords are weak, predictable, or reused across different accounts, attackers may find it easier to gain unauthorised access.

Some common password-related threats include:

Brute-force attacks: Cybercriminals attempt to guess passwords by trying numerous possible combinations.

Phishing attacks: Attackers send fraudulent emails or create fake websites to trick employees into revealing their login credentials.

Credential stuffing: Attackers use previously stolen usernames and passwords to attempt access to other accounts.

Password spraying: Attackers try commonly used passwords against multiple user accounts.

Social engineering: Cybercriminals manipulate individuals into revealing confidential information, including passwords.

These threats demonstrate why strong and unique passwords are important for protecting organisational information.

**4. ACSC Recommendations for Creating Strong Passwords**

Based on Australian Cyber Security Centre guidance, the following practices help improve password security.

**4.1 Create long passwords**

Use passwords of at least 15 characters where traditional password authentication is required.
Longer passwords are generally more difficult for attackers to guess.
Consider using a passphrase made up of four or more unrelated words.

**4.2 Make passwords unpredictable**

Avoid personal information such as names, birthdays, and phone numbers.
Avoid common passwords and predictable combinations.
Do not use easily guessed patterns or famous quotations.
Choose unrelated words when creating a passphrase.

**4.3 Use unique passwords**

Create a different password for every account.
Never reuse work passwords on personal accounts.
Avoid using the same password across multiple business applications.

**4.4 Use a trusted password manager**

Use a reputable password manager to generate and store strong passwords.
Protect the password manager with a strong master password and MFA.
Avoid storing passwords in unsecured documents or notes.
Use the password manager to help maintain unique passwords for different accounts.

**4.5 Enable multi-factor authentication (MFA)**

Enable MFA wherever it is available.
Use an additional verification method when accessing important accounts.
Prefer phishing-resistant authentication methods where supported.

**4.6 Consider using passkeys**

Use passkeys where supported as an alternative to traditional passwords.
Passkeys use cryptographic authentication and help protect against phishing.
Protect the devices and accounts used to access passkeys.

**5. Password Management Best Practices**

Employees should follow these practices to protect their accounts:

Keep passwords confidential.
Never share work passwords with colleagues or other individuals.
Avoid using personal information in passwords.
Use a trusted password manager.
Enable MFA on important accounts.
Avoid entering credentials into suspicious websites.
Verify website addresses before signing in.
Change passwords immediately if they are suspected to be compromised.
Avoid saving passwords on shared or public computers.
Report suspicious login notifications to the IT security team.
Use passkeys where supported.
Never approve unexpected MFA authentication requests.


### 6. Examples of Password Security Practices

| Password Practice | Example | Security Assessment |
|---|---|---|
| Using personal information | Birthday or phone number | Weak – easily guessed or discovered. |
| Using common passwords | Password123 | Weak – predictable and commonly used. |
| Reusing passwords | Same password for work and personal accounts | Risky – one compromised account can expose others. |
| Creating a passphrase | Four or more unrelated words | Better – provides length and unpredictability. |
| Using a password manager | Generating unique passwords for each account | Recommended – supports secure password management. |
| Enabling MFA | Password plus an additional verification method | Recommended – adds another layer of protection. |
| Using passkeys | Signing in with a supported device or security key | Recommended – provides phishing-resistant authentication. |


**7. Security Awareness Recommendations for Employees**

Employees play an important role in protecting organisational systems and information.

The following measures should be encouraged:

Participate in regular cyber security awareness training.
Learn how to recognise phishing emails and fraudulent websites.
Never disclose passwords through email or suspicious messages.
Use unique passwords for work-related accounts.
Report suspected credential theft immediately.
Use approved password management tools.
Enable MFA wherever available.
Follow organisational password security policies.

**8. Recommended Organisational Security Measures**

Organisations should establish effective password security policies to reduce the risk of unauthorised access.

Recommended measures include:

Enforce strong authentication requirements.
Implement multi-factor authentication across business applications.
Provide employees with approved password management solutions.
Monitor unusual login attempts and suspicious account activity.
Conduct regular employee security awareness training.
Apply access controls based on job responsibilities.
Establish procedures for reporting compromised accounts.
Review and improve password security policies regularly.

**9. Importance of Password Security**

Implementing strong password security practices can help an organisation:

Reduce the risk of unauthorised account access.
Protect sensitive customer and employee information.
Reduce the impact of stolen credentials.
Improve protection against phishing attacks.
Strengthen organisational security awareness.
Encourage safer authentication practices.
Improve the organisation's overall security posture.

**10. Conclusion**

Password security is an essential part of protecting organisational information and preventing unauthorised access.

Weak and reused passwords can expose sensitive information and create opportunities for cybercriminals to compromise business systems.

By following Australian Cyber Security Centre recommendations, employees can improve their password security through the use of long, unpredictable, and unique passwords, trusted password managers, multi-factor authentication, and passkeys.

Organisations should also invest in employee security awareness training, effective access controls, and continuous monitoring.

These measures contribute to a stronger security culture and help protect the organisation against password-related cyber threats.
