**Task 4: Penetration Testing**
**Commonwealth Bank Cybersecurity Virtual Experience**

**1. Introduction**

Penetration testing is a security assessment technique used to identify vulnerabilities in applications, systems, and networks.

This project focuses on understanding common web application vulnerabilities through practical exercises provided by PortSwigger Web Security Academy.

The exercises cover common security weaknesses that could affect real-world web applications if appropriate security controls are not implemented.

**2. Objectives**

The objectives of this project are to:

Understand the principles of penetration testing.
Identify common web application vulnerabilities.
Develop knowledge of SQL injection and cross-site scripting.
Understand authentication and access control weaknesses.
Learn about path traversal and operating system command injection.
Understand how vulnerabilities can affect organisations.
Develop a structured penetration testing report.
Recommend appropriate security controls and mitigation strategies.

**3. Testing Environment**

Platform: PortSwigger Web Security Academy

Website: https://portswigger.net/web-security

Testing environment: PortSwigger authorised educational labs.

Number of required labs: 11 beginner-level labs.

All practical testing activities are restricted to the authorised training environment.

**4. Vulnerability Categories**

The project covers the following web application security topics:

SQL Injection
Cross-Site Scripting (XSS)
Access Control Vulnerabilities
Authentication Vulnerabilities
Path Traversal
OS Command Injection

**5. Project Deliverables**

The following deliverables are included in this project:

A professional penetration testing report.
Descriptions of the vulnerabilities investigated.
Key findings from the completed labs.
Security recommendations for mitigating vulnerabilities.
Screenshots documenting lab completion.
An overall analysis of web application security risks.

**6. Learning Outcomes**

Through this project, I aim to develop a better understanding of web application security, vulnerability identification, risk assessment, and security reporting.

The practical exercises also demonstrate why secure coding, proper authentication, access control, and input validation are essential for protecting web applications.

**7. Conclusion**

This project provides practical exposure to common web application security vulnerabilities through an authorised learning environment.

The knowledge gained will help develop foundational penetration testing skills and improve my ability to identify security weaknesses and recommend appropriate remediation measures.
